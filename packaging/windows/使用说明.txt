CustomTrader 量化交易终端（Windows 桌面版）
==========================================

安装：双击 install.bat（创建桌面/开始菜单快捷方式），数据保存在本目录 data\ 下
启动：双击桌面「CustomTrader 量化交易终端」图标，或直接双击 CustomTrader.exe
数据：全部保存在程序目录的 data\ 子目录（数据库、配置、日志）——拷贝该目录即完整备份
卸载：直接删除程序目录

原生窗口依赖：Windows 10/11 自带 WebView2，无需额外安装（老系统若弹窗提示请安装
Microsoft Edge WebView2 Runtime）。

首次登录账号 admin / admin（请登录后立即在设置页修改密码）。

数据源配置（设置页）：
- A股行情：STOCK 网关（无需配置，真实公开行情）
- 期货/期权分时：FUYAO 网关，需填入同花顺 fuyao API Key
- 期货交易：CTP 网关，填入期货公司前置地址与账号（留空 md_address 可只交易不看其行情）

免责声明：本软件仅供学习研究，不构成投资建议，据此交易风险自负。

────────────────────────────────────────
客户端模式（连接远程服务器，可选）
────────────────────────────────────────
如果只想把本程序当作某台服务器上 CustomTrader 的桌面客户端
（数据在服务器，本机不另存数据）：

1. 在程序目录新建文件 remote.url（无扩展名），内容一行写服务器地址，
   例如：https://your-server.com
2. 双击 CustomTrader.exe → 原生窗口直接打开服务器页面（不启动本机引擎）
3. 若服务器使用自签名证书（地址栏提示“不安全”），请先安装服务器证书：
   双击证书文件 → 安装证书 → 本地计算机 → 将所有的证书放入下列存储 →
   浏览选择「受信任的根证书颁发机构」→ 完成。之后重开窗口即可。

删除 remote.url 即恢复本机模式（数据在本机 data\ 目录）。
